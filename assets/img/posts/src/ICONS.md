# Icons used in the post diagrams

The diagrams embed official Microsoft icons, used under Microsoft's terms for architecture diagrams, training material and documentation (do not crop, distort or use them to represent another product):

- Microsoft Fabric icons: npm package `@fabric-msft/svg-icons` 12.0.0, see https://learn.microsoft.com/fabric/get-started/icons
- Azure architecture icons (Microsoft Foundry, Application Insights, Users, Managed Identities): https://learn.microsoft.com/azure/architecture/icons
- Power Platform icons (Copilot Studio): https://learn.microsoft.com/power-platform/guidance/icons

The SVG sources in this folder are generated; the PNGs next to the posts are what the site serves.
